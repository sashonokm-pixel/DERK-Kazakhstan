# DERK — Digital Ethnic Representation of Kazakhstan

Экспортируемый исследовательский прототип v0.1: публичная карта + аналитический кабинет.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Для публикации: загрузите папку в GitHub-репозиторий, затем создайте приложение на https://share.streamlit.io/ и укажите `app.py` как точку входа. После публикации приложение получит ссылку. Учтите правила публикации данных и лицензии хостинга.

## Структура
- `app.py`: интерфейс, фильтры, визуализация, загрузка и экспорт
- `data/regions.csv`: приближённые координаты центров 17 областей и 3 городов республиканского значения
- `data/observations.csv`: пустой шаблон для исследовательских записей
- `ARCHITECTURE.md`: техническая архитектура, дорожная карта и методология

## Формат записи
`record_id, ethnic_group, region, platform, community_name, public_url, language, topic, followers, observed_at, source_url, verification_status, notes`

`verification_status`: `pending`, `verified`, `rejected`. В публичном режиме доступны только `verified`.

Пример формата **не является фактическим наблюдением**: `DEMO-1,Пример этноса,г. Алматы,Facebook,Демонстрационное сообщество,https://example.org,русский,культура,0,2026-10-14,https://example.org,pending,Синтетический пример — не включать в исследования`.

## Ограничения версии 0.1
- Карта отображает **точки-центроиды**, не географические границы областей.
- Загрузка CSV — только в текущую сессию, без постоянного серверного хранения.
- Исследовательский кабинет **не защищён авторизацией**: нельзя загружать конфиденциальные данные в публично доступный экземпляр.
- Приложение не собирает автоматически данные соцсетей и не оценивает этничность людей.
- Число записей не является показателем распространённости этноса и не должно трактоваться как индекс репрезентации.
- Для продуктивного использования требуются PostgreSQL, роли, модерация, журналы изменений и геометрия границ с лицензированным источником.


## Ручной ввод (v0.2)
В исследовательском кабинете есть форма добавления наблюдений и таблица для редактирования/удаления записей. Записи имеют статусы pending, verified, rejected. Публичный режим отображает только verified. Все изменения в текущей версии хранятся в памяти сессии Streamlit: обязательно экспортируйте полную базу CSV после работы. При следующем запуске импортируйте её через загрузчик CSV (импорт заменяет текущую рабочую таблицу). Для постоянной многопользовательской работы потребуется PostgreSQL и авторизация.
